# Gangue Da Welcia 5.2 (Minecraft 1.8.9 / Forge)

Cada push neste repositorio compila o mod sozinho na aba **Actions**.
O .jar aparece em **Artifacts** (GangueDaWelcia-jar). Use o que NAO termina em `-sources`.

## Controles
- Right Shift: abre o menu do client.
- Menu > Editar posicoes: arraste os elementos e arraste o quadradinho do canto de cada um para mudar o tamanho (+ / - tambem funcionam).
- Abas: HUD, Combate, Mira (18 estilos + personalizacao), Utilidades, Interface, Aparencia, Tamanho.
- As opcoes ficam salvas em config/familiasantana.properties.

## Novidades da 5.1
- **Alvo**: barra de vida, nome e distancia do inimigo que voce acerta ou mira.
- **Hits** (dados | recebidos) e **Abates** (K/D) - zeram ao trocar de mundo/servidor.
- **Sessao**: tempo de jogo; **Rotacao**: yaw / pitch; **Grafico FPS**: mini grafico dos ultimos segundos.
- **Aviso Vida Baixa**: borda vermelha pulsando com 3 coracoes ou menos.
- **Toggle Sneak**: tecla Z liga/desliga o agachar travado.
- **Zoom Scroll**: com o zoom (C) apertado, o scroll aproxima/afasta; o zoom agora e suave.
- **Notificacoes**: avisos rapidos no topo (Toggle Sneak, HUD...).
- Tecla **H** esconde/mostra todo o HUD.
- As teclas podem ser mudadas em Controles > Gangue Da Welcia.
- Aba Tamanho agora em 3 colunas.

## Novidades da 5.2
- Nome do client agora e **Gangue Da Welcia**.
- Aba Aparencia: **Transparencia do menu** (deixa o menu do client meio transparente).
- Aba Aparencia: escolha o **fundo da tela inicial** (A - Classico ou B - Aurora). Tambem da para trocar pelos botoes A / B na propria tela inicial.
- Editor de HUD: quadradinho no canto de cada elemento para mudar o tamanho so com o mouse.
